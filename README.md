## What I'm building toward

- **Systems:** Understanding the boundary between applications, operating systems, and hardware.
- **Networking:** Understanding what happens between a client sending a request and a server returning a response.
- **Backend engineering:** Building reliable software and understanding its performance, concurrency, and data flow.
- **Databases:** Going beyond queries to understand indexes, transactions, and storage.
- **Computer science:** Building mental models from fundamentals instead of memorizing abstractions.

## Engineering philosophy

```text
Understand the mechanism.
Question the abstraction.
Measure before optimizing.
Debug from evidence.
Know what your code depends on.
```

I value explanations that survive contact with reality, experiments that can be reproduced, and code I can explain down to the mechanisms that make it work.
